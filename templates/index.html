CI that can’t upgrade yet, kept running.

A JDK that isn't approved yet, build hosts on AIX, Solaris or HP-UX, a vendor tool pinned to one version: plenty of CI can't move to what upstream supports. keelinfra keeps shipping tested, open-source builds for it until it can, and publishes the CI runs and test data behind what it says.

Extended Security for Jenkins 2.541.x

keelinfra/jenkins-extended-security · MIT
Released Not an official Jenkins release

Jenkins 2.541.3, the last LTS that runs on Java 17, with the core security fixes released after it.

  • Each fix listed with its upstream commit and any change from upstream
  • Built and tested in public CI on Java 17 and 21
  • A reproducible WAR, with a checksum, an SBOM and a build attestation
  • A Docker image that runs like the official one, for amd64 and arm64
GitHub What it covers

Agent8 for Jenkins

keelinfra/agent8 · MIT
Available Tested on AIX · Solaris · HP-UX

Run Jenkins agents on hosts stuck on Java 8, 11 or 17, while the controller moves to Java 21.

  • The old host keeps its Java and stays an ordinary node
  • Tested in CI on Linux, including RHEL/CentOS 6
  • Releases named after the Jenkins version they were tested with, one install script

AIX Runner for GitLab

keelinfra/aix-runner · MIT
Experimental Tested on AIX 7.3

GitLab Runner for AIX 7.2 and 7.3, which GitLab doesn't ship.

  • The unmodified upstream runner, with four small dependency patches
  • The latest upstream release built daily in CI; releases published by hand
  • Shell executor tested: jobs, artifacts, cache, git clone, cancel

How every keelinfra project works

01

Open source first

The code, install scripts and tests are public. You can run everything without talking to us.

02

Tested in public

Linux, the upgrade rehearsals and the security backports are tested in public CI you can check. AIX, Solaris and HP-UX are tested by hand, not in CI, and the pages say so. The evidence ledger →

03

Built with its users

Bugs, questions and fixes go to each project's GitHub issues and pull requests, where the answer helps the next person too. How to help →

Infrastructure you have to run yourself, kept current.

Regulation, air gaps and hardware that isn't going anywhere keep a lot of systems off the cloud and off the upgrade path. keelinfra builds open-source tools that keep them supported, and publishes the CI runs and test data behind what it says.

Agent8 for Jenkins

keelinfra/agent8 · MIT
Available Free Tested on AIX · Solaris · HP-UX

Run Jenkins agents on hosts stuck on Java 8, 11 or 17, while the controller moves to Java 21.

  • The old host keeps its Java and stays an ordinary node
  • Tested in CI on Linux, including RHEL/CentOS 6
  • Releases named after the Jenkins version they were tested with, one install script
